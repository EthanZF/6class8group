关系图（文字说明）



accounts.BlogUser ──1:N──> Article ──N:1──> Category ──(自关联)──> Category（树形父分类）

&#x20;                              │

&#x20;                              └──M:N──> Tag



SideBar / Links / BlogSettings ── 独立表，无外键



comments.Comment ──N:1──> Article（反向：article.comment\_set）

comments.Comment ──N:1──> accounts.BlogUser

comments.Comment ──(自关联 parent\_comment)──> Comment

comments.CommentReaction ──N:1──> Comment / BlogUser



要点：



\- 分类树 通过 Category.parent\_category 自关联实现；get\_category\_tree() 递归取父链，get\_sub\_categorys() 递归取子孙。

\- 文章↔标签 多对多，通过 Django 中间表关联。

\- 文章归属：一篇文章必属于一个分类和一个作者（均 CASCADE）。

\- 侧边栏最新评论由 comments.Comment 提供，按 is\_enable=True 且 -id 排序取前 N 条。

\- SideBar 与 Links 的 sequence 唯一，保证排序稳定；get\_or\_create 时不要复用已删除记录的 sequence。

\- BlogSettings 是单例，通过 clean() 校验，任何写入都会清空全站缓存。
